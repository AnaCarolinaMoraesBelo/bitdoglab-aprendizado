
# BitDogLab - Aprendizado

Repositório dedicado ao meu aprendizado em
sistemas embarcados utilizando a BitDogLab V6.3.

## Objetivo

Aprender programação e eletrônica na prática,
começando pelos fundamentos e evoluindo
gradualmente para projetos mais complexos.

## Tecnologias

- BitDogLab V6.3
- Raspberry Pi Pico W
- MicroPython
- Visual Studio Code
