
# BitDogLab - Aprendizado

Repositório dedicado ao meu aprendizado em
sistemas embarcados utilizando a BitDogLab V6.3.

## Objetivo

Aprender programação e eletrônica na prática,
começando pelos fundamentos e evoluindo
gradualmente para projetos mais complexos.

## Tecnologias

- BitDogLab V6.3
- Raspberry Pi Pico W
- MicroPython
- Visual Studio Code


## Placa utilizada

Neste projeto, estou utilizando a **BitDogLab V6.3**, desenvolvida para atividades práticas de sistemas embarcados no contexto do programa EmbarcaTech.

**Especificações:**
- **Placa:** BitDogLab V6.3
- **Microcontrolador:** RP2040 (Raspberry Pi Pico W)
- **Linguagem:** MicroPython
- **Ambiente de desenvolvimento:** Visual Studio Code
- **Componentes:** display OLED, matriz 5x5 de LEDs RGB, LED RGB individual, joystick, botões, buzzers e microfone.

A ideia é explorar os componentes da placa aos poucos, começando pelos fundamentos e avançando conforme aprendo novos conceitos.
